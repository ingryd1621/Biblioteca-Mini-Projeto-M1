Controle para Biblioteca em JS

Sobre o projeto

Este projeto consiste em um sistema de gerenciamento de biblioteca desenvolvido em JavaScript para execução no terminal. O sistema permite realizar operações como listar livros, buscar livros por título, registrar empréstimos e devoluções, cadastrar novos livros, listar apenas os livros disponíveis e exibir estatísticas da biblioteca.

O projeto foi desenvolvido como atividade prática do Módulo 01, com foco na aplicação dos conceitos fundamentais da linguagem JavaScript e da organização de projetos utilizando Git e GitHub.

Objetivo

Praticar os principais conceitos do Módulo 01:

- Variáveis e constantes
- Estruturas condicionais (`if` e `switch`)
- Estruturas de repetição
- Funções
- Arrays
- Métodos de arrays (`forEach`, `filter`, `find`, `push`, `map`)
- Objetos
- Classes
- Importação e exportação de módulos (`import` e `export`)
- Manipulação de entrada de dados com `prompt-sync`
- Organização de código em módulos
- Controle de versão com Git e GitHub (branches, commits e merge).

Como executar

1. Clone o repositório do GitHub.
2. Acesse a pasta pelo terminal.
3. Execute o comando: node index.js
